CSS Types Implementation - Personal Resume

Description

This project is a static HTML web page created for a college assignment to demonstrate the use of different CSS integration methods. It displays a professional resume structured with clean HTML5 semantics.

Assignment Requirements Met

This project successfully implements all three types of Cascading Style Sheets (CSS):

External CSS: Managed through the styles.css file to handle global styles (e.g., body typography, lists).

Internal CSS: Placed within the <style> tags in the <head> of index.html to manage component-specific layouts.

Inline CSS: Applied directly to HTML elements using the style="..." attribute (e.g., on the header and specific text spans).

File Structure

index.html - The main HTML document containing the resume content, inline styles, and internal styles.

styles.css - The external stylesheet linked to the HTML file.

How to View

Since this is a static webpage, no installation or server is required.

Download or clone this repository.

Double-click the index.html file to open it in any modern web browser (Chrome, Safari, Edge, Firefox).
